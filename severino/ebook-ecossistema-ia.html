Parte 2

VPS Hostinger do Zero

2.1 Criar a VPS

  1. Hoster Home → VPS → KVM 1 ou 2 (2 vCPU / 4 GB RAM / 80 GB).
  2. Sistema Operacional: Ubuntu 22.04 ou 24.04.
  3. Defina root password forte (ou chave SSH).
  4. Anote o IP (ex.: 187.127.42.146).

2.2 Primeiro acesso e instalação base

ssh root@SEU_IP

# Atualizar sistema
export DEBIAN_FRONTEND=noninteractive
apt update && apt upgrade -y

# Node.js 22
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt-get install -y nodejs
node -v   # v22.x

# PM2
npm install -g pm2

# Nginx + Certbot
apt-get install -y nginx certbot python3-certbot-nginx

# ffmpeg (vídeos/cards)
apt-get install -y ffmpeg

# git + ferramentas
apt-get install -y git curl unzip

2.3 Habilitar PM2 na inicialização

pm2 startup systemd
pm2 save
Parte 3

OpenRouter — o Cérebro Barato

  1. Acesse openrouter.ai → crie conta (Google/GitHub).
  2. Wallet → Deposit com ~US$ 5–10 para começar.
  3. Aba Keys → Create Key → copie a chave sk-or-v1-....
  4. Monte sua config de modelos:
LLM_MODEL_BARATO=openrouter/free            # agentes do dia a dia
LLM_MODEL_FORTE=deepseek/deepseek-v3.2       # estratégia, análise
LLM_BUDGET_TOKENS_DIA=200000                 # teto diário
💡 Economia: o Guardião de Saldo consulta o saldo real do OpenRouter (GET /api/v1/credits) e bloqueia gasto abaixo de 50% do mínimo definido.

Reforço opcional: roteador free-first (9Router)

npm install -g 9router       # dashboard em http://localhost:20128

# no .env:
LLM_BASE_URL=http://localhost:20128/v1/chat/completions
LLM_MODEL_BARATO=free-first
LLM_MODEL_FORTE=gpt-4o-mini
Parte 4

OpenCode — o Construtor no seu PC

  1. Instale a extensão OpenCode no VS Code (ou o CLI no seu PC).
  2. Configure o provedor/modelo apontando para o OpenRouter.
  3. Fluxo: você descreve a peça → o OpenCode lê os arquivos existentes → escreve no padrão do projeto → você sincroniza para a VPS.

As regras que o OpenCode segue (padrão do ecossistema)

- Node puro + fetch (sem framework externo)
- Reaproveitar: require('../ia'), require('../muapi'), require('../canais')
- Prompt de imagem/vídeo em INGLÊS; copy/legenda em PT-BR
- Segredos SÓ no .env
- Portas: 3335 (orquestrador) · 3334 (painel produto) · 4007 (Postiz)
🔧 Dica: guarde essas regras num CONSTITUICAO.md e peça ao OpenCode para segui-las em toda sessão.

  && node animar_card.js && node publicar_redes.js

Parte 8 · Fase 3

Pagamentos — Kiwify Webhook Autenticado

  1. Crie o produto no Kiwify (ex.: R$ 47/mês mensal e anual).
  2. Em Integrações → Webhooks: https://seu-dominio.com/api/purchase/webhook?secret=SEU_SECRET

Fluxo validado no projeto real

Kiwify ──POST──► /api/purchase/webhook
   ├─ valida secret (query ?secret= | header x-webhook-secret | body.secret)
   ├─ ignora: boleto_gerado, pix_gerado, carrinho_abandonado, chargeback
   ├─ compra aprovada → gera licença VIP-* + purchases.json
   └─ posta venda.confirmada → orquestrador → cobrador → funil.registrarCompra()
💰 Nunca creditar POST aberto. Crédito real SÓ com assinatura válida. Kiwify envia em centavos (47 → R$0,47; 4700 → R$47,00) — normalize.
Parte 9

Deploy na Prática (OpenCode → VPS)

Sincronizar do PC

scp arquivo.js root@SEU_IP:/root/severino/ecosystem/arquivo.js

Sequência de deploy segura

cd /root/severino/ecosystem
node --check arquivo.js        # 1. sintaxe
pm2 restart ecosistema          # 2. reiniciar
pm2 logs ecosistema --lines 20 # 3. conferir heartbeat
pm2 save                        # 4. persistir

Antes de tocar no servidor compartilhado

cp servidor.js servidor.js.pre-$(date -I)
cp /etc/nginx/sites-enabled/severino /root/severino/nginx_severino.bak
nginx -t

Guardião de Saldo (não queima crédito à toa)

  • Consulta saldo REAL do OpenRouter e MuAPI
  • Alerta por degrau (queda de 3% do mínimo)
  • Trava pré-gasto: saldo ≤ 50% do mínimo → evento bloqueado
  • Segurança: se não conseguir consultar → ok:true (nunca bloqueia na dúvida)
